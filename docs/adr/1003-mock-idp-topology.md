# 1003 — T10 runs navikt/mock-oauth2-server in-cluster over HTTPS, reached from the dev Mac by port-forward

* Status: accepted (2026-10-02)

## Context
T10 tests Cucina's identity paths against `navikt/mock-oauth2-server` 6.0.4 with Google- and GitHub-shaped issuers (§13: no
live Google client or GitHub workflow). The STS (internal/auth) requires HTTPS issuer and discovery URLs and rejects a discovery
document whose `issuer` differs from the TrustPolicy's. mock-oauth2-server derives each issuer URL from the request's host, so
the STS (in-cluster) and the test driver (dev Mac) must address it by the same URL; the dev Mac cannot resolve cluster DNS and
installing anything system-wide (hosts entries, trust settings) is forbidden on it (§12).

## Decision
* Run the mock as a pod with a Service on port 30443 and TLS from a throwaway CA generated by
  `deploy/aws-e2e/scripts/campaign/mock-oauth2-server.sh` (key material under `~/.config/cucina/aws-e2e/mock-idp/`, never in
  the repo). Issuers: `/google`, `/google-short` (30 s tokens, for the expired-token case) and `/github`. Request mappings keyed
  by the requested scope select the claims of each case (valid, wrong `hd`, unverified e-mail, wrong `aud`, foreign repository,
  `pull_request_target`, a valid `main` push).
* The issuer URL is the in-cluster name (`https://mock-oauth2-server.cucina-e2e.svc.cluster.local:30443/<issuer>`); the
  campaign's TrustPolicies trust it with the mock CA in `issuer.certificateAuthority`.
* On the dev Mac a `kubectl port-forward` exposes the Service on `127.0.0.1:18443`. The harness dials that address for the
  in-cluster host name (TLS server name and Host header unchanged). For `cucinactl login` (T10a) the harness runs a loopback
  CONNECT proxy that only tunnels to the mock, passed as `HTTPS_PROXY`, and points `SSL_CERT_FILE`/`CUCINA_EXTRA_CA_FILE` at the
  mock CA.

## Consequences
* T10a needs cucinactl's OIDC client to honour `HTTPS_PROXY` and an extra CA bundle; until it does, T10a fails with a TLS or
  DNS error that names the gap (open item for the cli agent).
* No component outside the campaign namespace changes; the mock and its policies are deleted with the release.
